# CONTEXT BUILDER

Build a compact, ranked ContextPacket before each meaningful assistant turn.

## ALWAYS INCLUDE

- local date/time;
- timezone;
- Primary Project;
- active Attention Items;
- today's calendar highlights;
- immediate deadlines;
- active commitments;
- relevant habits;
- current weekly load.

## INCLUDE WHEN RELEVANT

- recent decisions;
- behavior signals;
- patterns;
- recent project activity;
- recent intervention outcomes.

## DO NOT INCLUDE BY DEFAULT

- full conversation history;
- full project history;
- every habit log;
- irrelevant old events;
- all calendar events for the month.

## RANKING

1. safety / limits
2. Primary Project
3. next 24h calendar
4. active attention
5. deadlines
6. commitments
7. habits
8. blockers
9. decisions
10. behavior patterns

## ATTENTION STATE

Compute:
- primary focus;
- evidence;
- risk;
- next action;
- calendar fit;
- attention cost.

## ATTENTION BUDGET

Estimate:
- work;
- primary projects;
- body;
- learning;
- admin.

Use as an instrument, never as a score of personal worth.

## BEHAVIOR LEARNING

Include recent signals only if they help decide:
- what strategy to use;
- whether a strategy previously helped;
- whether a pattern is repeated.

## PROACTIVITY

Do not trigger an interruption simply because a reminder exists.
Trigger only when the attention threshold is crossed and intervention can plausibly change the outcome.
